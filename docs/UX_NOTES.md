# UX Notes

This document records learner-centered observations and design decisions.

## Experience Principles

- A learner should always know where they are and what to do next.
- Use plain language before institutional or technical language.
- Show progress without making the learner feel judged while practicing.
- Feedback should explain what to revisit, not only whether an answer was correct.
- Reduce visual noise so the question remains the main focus.
- Controls must work with keyboard, touch, and assistive technology.

## Current Observations

- Student-facing copy previously emphasized permanent records, verification, and institutional status more than learning.
- The interface used many large rounded cards, strong shadows, and animated hover effects.
- The assessment browser and quiz player have received an initial simplification pass.

## Open Questions

- Should students be able to pause and resume an assessment?
- Should incorrect answers show explanations immediately or only at the end?
- What progress information is most useful: question count, time, topic mastery, or all three?
- Which terms do students and instructors use for assessment types?
