# Bugs

Use one entry per reproducible issue. Keep status current.

## Status Values

- `Open`: confirmed and waiting for work
- `In progress`: actively being fixed
- `Blocked`: waiting on an external decision or dependency
- `Resolved`: fixed and validated
- `Won't fix`: intentionally not addressing

## Priority Values

- `P0`: prevents core use or risks data/security
- `P1`: major workflow is broken
- `P2`: important usability or correctness issue
- `P3`: minor issue or polish
